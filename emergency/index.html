Threat model for AI agentsBedrohungsmodell für KI-AgentenModelo de ameaças para agentes de IA

AI agents execute shell commands, read and write files, use credentials and call external APIs. They do this autonomously, often over many steps and with few checkpoints. That creates risks that traditional security tooling was not built for.

KI-Agenten führen Shell-Befehle aus, lesen und schreiben Dateien, nutzen Zugangsdaten und rufen externe APIs auf. Sie tun das autonom, oft über viele Schritte und mit wenigen Kontrollpunkten. Daraus entstehen Risiken, für die klassische Sicherheitswerkzeuge nicht gebaut wurden.

Os agentes de IA executam comandos de shell, leem e escrevem ficheiros, usam credenciais e chamam APIs externas. Fazem-no de forma autónoma, muitas vezes ao longo de muitos passos e com poucos pontos de controlo. Daí surgem riscos para os quais as ferramentas de segurança tradicionais não foram concebidas.

  • OWASP LLM01:2025OWASP ASI01Prompt injectionPrompt InjectionPrompt injection

    Text planted in a file, an issue or a web page redirects the agent in the middle of a task.

    Eingeschleuster Text in einer Datei, einem Issue oder auf einer Webseite lenkt den Agenten mitten in der Aufgabe um.

    Texto plantado num ficheiro, num issue ou numa página web desvia o agente a meio de uma tarefa.

  • OWASP LLM06:2025OWASP ASI02Unintended destructive actionsUnbeabsichtigte destruktive AktionenAções destrutivas não intencionais

    The agent misreads an instruction and runs something irreversible, such as a recursive delete, a force push or a DROP TABLE.

    Der Agent deutet eine Anweisung falsch und führt einen nicht umkehrbaren Befehl aus, etwa ein rekursives Löschen, einen Force-Push oder ein DROP TABLE.

    O agente interpreta mal uma instrução e executa algo irreversível, como uma eliminação recursiva, um force push ou um DROP TABLE.

  • OWASP LLM02:2025OWASP ASI02Secret exfiltrationAbfluss von GeheimnissenFuga de segredos

    While debugging, the agent reads .env or credential files and sends the content outbound, through a tool call, a URL or the model context.

    Beim Debuggen liest der Agent .env oder Zugangsdaten-Dateien und überträgt den Inhalt nach außen, über einen Tool-Aufruf, eine URL oder den Modellkontext.

    Ao depurar, o agente lê .env ou ficheiros de credenciais e envia o conteúdo para fora, através de uma chamada a uma ferramenta, de um URL ou do contexto do modelo.

  • OWASP ASI03No visibility, no identityFehlende Sichtbarkeit und IdentitätSem visibilidade nem identidade

    An agent spawns subagents. The people using it cannot tell which instance did what, and on whose behalf.

    Ein Agent startet Subagenten. Für die Nutzenden bleibt unklar, welche Instanz was in wessen Auftrag getan hat.

    Um agente cria subagentes. Quem o usa não consegue saber que instância fez o quê, nem em nome de quem.

  • OWASP LLM06:2025OWASP ASI03Privilege escalationRechteausweitungEscalada de privilégios

    To fix a permission error, the agent edits sudoers, CI pipelines or file permissions.

    Um einen Berechtigungsfehler zu beheben, ändert der Agent sudoers, CI-Pipelines oder Dateirechte.

    Para corrigir um erro de permissões, o agente altera o sudoers, pipelines de CI ou permissões de ficheiros.

  • OWASP LLM03:2025OWASP ASI04Dependency manipulationManipulation von AbhängigkeitenManipulação de dependências

    Following injected input, the agent installs or rewrites a package.

    Auf Anweisung aus eingeschleustem Input installiert oder überschreibt der Agent ein Paket.

    Seguindo uma instrução injetada, o agente instala ou reescreve um pacote.

  • OWASP LLM03:2025OWASP ASI04Supply chain riskRisiko in der LieferketteRisco na cadeia de abastecimento

    Optimising for velocity, the agent installs a vulnerable package or one with a zero-day.

    Der Agent optimiert auf Geschwindigkeit und installiert dabei ein verwundbares oder ein 0-Day-behaftetes Paket.

    Ao otimizar a velocidade, o agente instala um pacote vulnerável ou com uma vulnerabilidade zero-day.

  • OWASP LLM05:2025OWASP ASI05Unexpected code executionUnerwartete CodeausführungExecução inesperada de código

    The agent generates code in real time and runs it. Injected input turns text into something executable, such as scripts, deserialised objects or template code, that reaches the host or leaves the sandbox.

    Der Agent erzeugt Code in Echtzeit und führt ihn aus. Eingeschleuster Input macht aus Text etwas Ausführbares, etwa Skripte, deserialisierte Objekte oder Template-Code, das den Host erreicht oder die Sandbox verlässt.

    O agente gera código em tempo real e executa-o. Input injetado transforma texto em algo executável, como scripts, objetos desserializados ou código de templates, que chega ao host ou sai da sandbox.

  • OWASP LLM08:2025OWASP ASI06Memory and context poisoningVergiftung von Gedächtnis und KontextEnvenenamento de memória e contexto

    Manipulated data lands in the agent’s memory, summaries or RAG store and skews later reasoning, planning and tool use, long after the original input.

    Manipulierte Daten gelangen in Gedächtnis, Zusammenfassungen oder RAG-Speicher des Agenten und verzerren spätere Planung und Tool-Nutzung, lange nach der ursprünglichen Eingabe.

    Dados manipulados chegam à memória, aos resumos ou ao repositório RAG do agente e distorcem o raciocínio, o planeamento e o uso de ferramentas muito depois da entrada original.

  • OWASP LLM04:2025Poisoned data and modelsVergiftete Daten und ModelleDados e modelos envenenados

    Tampered training, fine-tuning or embedding data plants backdoors or biased behaviour in the model the agent runs on.

    Manipulierte Trainings-, Fine-Tuning- oder Embedding-Daten pflanzen Hintertüren oder Verzerrungen in das Modell, auf dem der Agent läuft.

    Dados de treino, de fine-tuning ou de embeddings adulterados plantam backdoors ou enviesamentos no modelo em que o agente corre.

  • OWASP ASI07Insecure inter-agent communicationUnsichere Kommunikation zwischen AgentenComunicação insegura entre agentes

    Messages between agents lack authentication, integrity checks or validation, so they can be spoofed, intercepted or manipulated.

    Nachrichten zwischen Agenten sind weder authentifiziert noch auf Integrität oder Inhalt geprüft und lassen sich fälschen, abfangen oder verändern.

    As mensagens entre agentes não têm autenticação, verificação de integridade nem validação, e podem ser falsificadas, intercetadas ou alteradas.

  • OWASP ASI08Cascading failuresKaskadenfehlerFalhas em cascata

    A single fault, such as a hallucination, a corrupted tool or poisoned memory, spreads across agents and workflows and grows into system-wide damage.

    Ein einzelner Fehler, etwa eine Halluzination, ein manipuliertes Tool oder vergifteter Speicher, breitet sich über Agenten und Abläufe aus und wächst zu einem Schaden im ganzen System.

    Uma única falha, como uma alucinação, uma ferramenta corrompida ou memória envenenada, propaga-se por agentes e fluxos e cresce até um dano em todo o sistema.

  • OWASP LLM09:2025OWASP ASI09Exploited trust, false confidenceAusgenutztes Vertrauen, falsche GewissheitConfiança explorada, falsa certeza

    People over-rely on fluent, confident agent output and approve actions without checking, or the agent states falsehoods convincingly. The human sign-off becomes the weak point.

    Menschen verlassen sich auf flüssige, selbstsichere Agentenantworten und geben Aktionen ohne Gegenprüfung frei, oder der Agent behauptet Falsches überzeugend. Die menschliche Freigabe wird zur Schwachstelle.

    As pessoas confiam em respostas fluentes e seguras do agente e aprovam ações sem verificar, ou o agente afirma falsidades de forma convincente. A aprovação humana torna-se o ponto fraco.

  • OWASP ASI10Rogue agentsAbtrünnige AgentenAgentes desviantes

    A compromised or drifting agent leaves its intended scope while single actions still look legitimate, and rule-based controls do not catch it.

    Ein kompromittierter oder abdriftender Agent verlässt seinen vorgesehenen Rahmen, obwohl einzelne Aktionen legitim aussehen, und regelbasierte Kontrollen greifen nicht.

    Um agente comprometido ou à deriva sai do seu âmbito previsto, embora cada ação pareça legítima, e os controlos baseados em regras não o apanham.

  • OWASP LLM07:2025System prompt leakageOffenlegung des System-PromptsFuga do prompt de sistema

    The agent reveals its own instructions, and with them any keys, internal rules or system details that were placed there.

    Der Agent gibt seine eigenen Anweisungen preis und damit Schlüssel, interne Regeln oder Systemdetails, die dort hinterlegt wurden.

    O agente revela as suas próprias instruções e, com elas, chaves, regras internas ou detalhes do sistema que lá foram colocados.

  • OWASP LLM10:2025Unbounded consumptionUnbegrenzter VerbrauchConsumo ilimitado

    Loops, over-long chains or too many tool calls drive up compute and API costs or exhaust quotas, with no limit that stops the agent.

    Schleifen, zu lange Ketten oder zu viele Tool-Aufrufe treiben Rechen- und API-Kosten in die Höhe oder erschöpfen Kontingente, ohne dass ein Limit den Agenten stoppt.

    Ciclos, cadeias demasiado longas ou demasiadas chamadas a ferramentas fazem subir custos de computação e de API ou esgotam quotas, sem um limite que pare o agente.

Classic operating system and endpoint tools watch the kernel and the file system. They lack the context to judge whether an action belongs to the agent’s task. So AI stays either too risky or too restricted to be useful.

Klassische Betriebssystem- und Endpoint-Werkzeuge überwachen Kernel und Dateisystem. Ihnen fehlt der Kontext, um zu beurteilen, ob eine Aktion zur Aufgabe des Agenten gehört. Dadurch bleibt KI entweder zu riskant oder zu eingeschränkt, um nützlich zu sein.

As ferramentas clássicas de sistema operativo e de endpoint vigiam o kernel e o sistema de ficheiros. Falta-lhes o contexto para avaliar se uma ação pertence à tarefa do agente. Assim, a IA fica ou demasiado arriscada ou demasiado limitada para ser útil.
